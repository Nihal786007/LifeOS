# Screenshot provenance

Real running LifeOS web app captures, in light mode:

- Each JPEG is a 992 × 640 crop from the same browser viewport.
- Sidebar/account identity and browser chrome are excluded.
- Dashboard, Calendar, and Ask ATLAS show empty daily data; Focus Mode shows entry state; Reality Mirror shows setup.
- No event titles or account details are published.
- No personal Memory content was opened or captured.
- No model request, Focus session, connector write, or canonical mutation was performed for these captures.

These are not populated benchmarks or evidence of hosted-provider availability.
